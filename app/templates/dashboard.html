Como os dados são atualizados?

O painel consulta os focos de calor sob demanda no diretório oficial do INPE.

  • Com Data do CSV em branco, a aplicação usa o CSV mais recente.
  • Você pode informar nome, arquivo ou URL completa do CSV.
  • O CSV baixado é salvo em cache local para reduzir falhas temporárias.
  • Se o INPE demorar e a data estiver em branco, o painel tenta usar o cache mais recente.
  • Os dados são normalizados em memória antes de alimentar mapa, gráficos e tabela.
  • Produtos Sentinel-2 são consultados sob demanda no Brazil Data Cube STAC.
Exemplos aceitos: focos_diario_br_20260919 focos_diario_br_20260919.csv https://dataserver-coids.inpe.br/queimadas/queimadas/focos/csv/diario/Brasil/focos_diario_br_20260919.csv

Hoje os focos do INPE são consumidos via CSV online com cache; ainda não há sincronização automática periódica para o banco local.
